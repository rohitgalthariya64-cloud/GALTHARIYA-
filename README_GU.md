# Rohit Galthariya AI Studio — પ્રારંભિક Android પ્રોજેક્ટ

## APK કેવી રીતે મળશે?
આ પ્રોજેક્ટ GitHub repository ના `main` branch માં ફાઇલો તરીકે અપલોડ કર્યા પછી `.github/workflows/build-apk.yml` દ્વારા APK build કરવાનો પ્રયાસ કરે છે. GitHub માં ZIP ફાઇલ અપલોડ કરવાથી તે આપમેળે extract થતી નથી; ZIP ખોલીને અંદરની ફાઇલો/ફોલ્ડરો અપલોડ કરવા પડે છે.

Build સફળ થાય તો GitHub → Actions → સફળ workflow run → Artifacts માં `Rohit-Galthariya-AI-Studio-APK` ડાઉનલોડ કરો.

## મર્યાદા
આ પ્રારંભિક UI છે. AI સાથે સાચી વાતચીત, AI વીડિયો જનરેશન, અવાજ, લિપ-સિંક અને MP4 export માટે યોગ્ય AI services/API તથા સુરક્ષિત backend ઉમેરવાનું બાકી છે. API keys ને એપના કોડમાં જાહેર રીતે ન મૂકો.
